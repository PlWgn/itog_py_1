# Каталог товаров DummyJSON

Итоговый проект по курсу «Продвинутый Python».

Это сервис, который загружает товары с сайта [DummyJSON](https://dummyjson.com/products), сохраняет их в базу данных и отдает через API на FastAPI.

## Техническое задание

Нужно было:

- реализовать загрузку данных с сервиса DummyJSON;
- сохранить загруженные данные в БД с использованием SQLAlchemy;
- реализовать асинхронное сохранение данных в базу;
- разобрать данные на сущности: бренды, категории, товары (SKU), отзывы;
- реализовать API метод `/category/{category_name}`, который возвращает все товары категории;
- привести базу к 3NF, чтобы у таблиц были связи;
- реализовать API методы `/brands/`, `/brand/{brand_name}`, `/products/`;
- реализовать кэширование для сложных запросов;
- если таблиц нет, создавать их, чтобы скрипт запускался на новой базе.

## Что реализовано

- асинхронная загрузка всех категорий через `aiohttp`, категории делятся на пакеты по 5 штук;
- асинхронное сохранение в SQLite через `SQLAlchemy` и `aiosqlite`;
- при повторном обновлении новые товары добавляются, а существующие обновляются;
- таблицы создаются автоматически при запуске скрипта обновления или API;
- если при запуске API база пустая, она заполняется данными из DummyJSON;
- ответы API кэшируются в памяти на 60 секунд, после обновления через API кэш сбрасывается.

## Структура базы данных

База приведена к 3NF: в каждой таблице есть первичный ключ `id`, а повторяющиеся данные вынесены в отдельные таблицы.

| Таблица | Поля | Связи |
|---|---|---|
| `categories` | `id`, `name` | |
| `brands` | `id`, `name` | |
| `products` | `id`, `title`, `description`, `price`, `discount_percentage`, `rating`, `stock`, `sku` | `category_id` → `categories.id`, `brand_id` → `brands.id` |
| `reviewers` | `id`, `name`, `email` | |
| `reviews` | `id`, `rating`, `comment`, `date` | `product_id` → `products.id`, `reviewer_id` → `reviewers.id` |

У части товаров в DummyJSON нет бренда, поэтому `brand_id` может быть пустым.

Авторы отзывов вынесены в таблицу `reviewers`, потому что имя автора зависит от его email, а не от самого отзыва.

## Используемые библиотеки

Установка:

```bash
pip3 install -U -r requirements.txt
```

## Обновление данных

Загрузить все категории:

```bash
python3 update.py
```

Пример вывода:

```
Добавлено товаров: 194, обновлено товаров: 0
Время обновления: 2.5 сек.
```

Загрузить только некоторые категории:

```bash
python3 update.py beauty smartphones
```

Пример вывода:

```
Добавлено товаров: 0, обновлено товаров: 21
Время обновления: 0.55 сек.
```

## Запуск API

```bash
uvicorn main:app --reload
```

После запуска документация доступна по адресу `http://127.0.0.1:8000/docs`.

## Методы API

| Метод | Описание |
|---|---|
| `GET /category/{category_name}` | все товары указанной категории |
| `GET /brands/` | список всех брендов |
| `GET /brand/{brand_name}` | все товары указанного бренда |
| `GET /products/` | все товары (SKU), которые есть в базе |
| `POST /update/` | обновление данных из DummyJSON |

Названия категории и бренда не зависят от регистра. Если категория или бренд не найдены, возвращается ошибка 404.

### Примеры использования

Товары бренда:

```bash
curl http://127.0.0.1:8000/brand/Apple
```

```json
[
  {
    "title": "Apple MacBook Pro 14 Inch Space Grey",
    "description": "The MacBook Pro 14 Inch in Space Grey is a powerful and sleek laptop...",
    "price": 1999.99,
    "discount_percentage": 4.69,
    "rating": 3.65,
    "stock": 24,
    "sku": "LAP-APP-APP-078",
    "id": 78,
    "category": "laptops",
    "brand": "Apple"
  }
]
```

Список брендов:

```bash
curl http://127.0.0.1:8000/brands/
```

```json
[
  {"name": "Amazon", "id": 31},
  {"name": "Annibale Colombo", "id": 11},
  {"name": "Apple", "id": 15}
]
```

Товары категории:

```bash
curl http://127.0.0.1:8000/category/beauty
```

Несуществующая категория:

```bash
curl http://127.0.0.1:8000/category/nope
```

```json
{"detail": "Категория не найдена: nope"}
```

Обновление данных:

```bash
curl -X POST http://127.0.0.1:8000/update/
```

```json
{"added_count": 0, "updated_count": 194}
```
